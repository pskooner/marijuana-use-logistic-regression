# Model Summary

## Full Logistic Regression Model

The initial model included:

- Alcohol use
- Cigarette use
- Gender
- Race

Marijuana use was modeled as the binary response variable.

The full model was statistically significant compared with the intercept-only model.

Alcohol use and cigarette use were strong predictors of marijuana use.

Gender was also statistically significant.

Race was not statistically significant after adjustment for the remaining predictors.

---

## Model Selection

Three variable-selection methods were evaluated:

### Forward Selection

The forward-selection model retained:

- Alcohol use
- Cigarette use
- Gender

Race was excluded.

### Backward Elimination

The backward-selection model retained:

- Alcohol use
- Cigarette use
- Gender

Race was removed because it did not meet the selection criterion.

### Stepwise Selection

The stepwise model also retained:

- Alcohol use
- Cigarette use
- Gender

Race was excluded.

---

## Final Model

All three model-selection procedures converged on the same reduced model.

The final model therefore included:

- Alcohol use
- Cigarette use
- Gender

The agreement between model-selection procedures suggests that the selected model was stable across the evaluated approaches.
