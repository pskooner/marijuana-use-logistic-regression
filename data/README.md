# Data

This directory contains the dataset used in the analysis.

## Dataset

`Substance2.dat`

The dataset contains aggregated observations of substance use among high school seniors.

Variables include:

- Alcohol use
- Cigarette use
- Marijuana use
- Gender
- Race
- Frequency count

Marijuana use is the binary outcome variable.

Alcohol use, cigarette use, gender, and race are evaluated as explanatory variables.

The `count` variable represents the number of observations corresponding to each combination of categorical characteristics.
