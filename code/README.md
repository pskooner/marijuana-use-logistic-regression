# Code

This directory contains the statistical analysis scripts used in the project.

## R

`marijuana_use_analysis.R`

The R workflow includes:

- Data import
- Variable recoding
- Reference-category specification
- Binary logistic regression
- Odds ratio estimation
- Forward selection
- Backward elimination
- Stepwise model selection
- AIC comparison

## Stata

`marijuana_use_analysis.do`

The Stata workflow includes:

- Data entry
- Frequency-weighted logistic regression
- Full-model estimation
- Intercept-only model estimation
- Likelihood-ratio testing
- Forward selection
- Backward elimination
- Stepwise selection
- AIC and BIC comparison

The two scripts provide parallel implementations of the same statistical analysis in R and Stata.
